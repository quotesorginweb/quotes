# Quotes.org.in project overview

Quotes.org.in is a source-led quotation discovery and image platform. It is not a bulk quote list and does not publish pages directly from keyword imports.

## Current milestone

- Responsive public home, topic and author templates
- Verified public-domain demonstration records
- Deterministic UTC quote of the day
- Server-rendered search with `noindex,follow`
- Copy, share, device-local favourites and reporting entry points
- Browser-local 1080×1080 PNG generator
- Metadata, canonicals, robots and sitemap
- Publication boundary and negative-intent classifier
- Editorial policy and architecture decisions

## Reference-project assumption

The requested Calculator.org.in repository and SEMrush workbook were not present in the supplied workspace. The implementation preserves the pinned Sites starter versions and records this as an input gap. No proprietary keyword data is served publicly.
