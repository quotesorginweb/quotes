# SEO strategy and indexability

| Route | Indexing | Canonical |
|---|---|---|
| `/`, hubs, approved topic/author pages | index, follow | self |
| `/search` | noindex, follow | none |
| `/quote/[stable-slug]` | noindex, follow by default | strongest collection |
| drafts, admin, reports | blocked/noindex | none |
| future daily archives | absent until publication | dated self URL |

One page owns each intent. Close variants consolidate into the strongest collection. Facets remain non-indexable until demand, sufficient verified content, unique editorial value and approval are all documented. Structured data must match visible content; rich results are never promised.
